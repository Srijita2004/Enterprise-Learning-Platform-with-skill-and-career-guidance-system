# SkillSphere Nexus M3 Frontend

This is the final integrated Angular frontend for Milestone 3 Certification Management. It was created in a new M3 folder from the submitted integrated frontend baseline so the locked submitted project remains unchanged.

## New M3 workspace

- Certification Command
- Certification Registry
- Renewals & Alerts
- Compliance Verification
- Reports & Audit

All important M3 data comes from the backend through `/certification-api/api`.

## Run

```powershell
npm install
npm start
```

Open `http://localhost:4200`.

The API Gateway must expose the M3 route described in the root project `integration/api-gateway-m3-route.yml` file.
